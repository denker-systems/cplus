  - Added `ShowPrompt()` and `HidePrompt()` to IQuestInteractable
  - TextRenderComponent on NPCs ("Press E to talk")
  - TextRenderComponent on collectibles ("Press E to collect")
  - Billboard effect on NPC prompts (faces camera)

- **Bug Fixes:**
  - Fixed `NotifyQuestEvent` to check all active quests when QuestID is NAME_None
  - Fixed `QuestTrackerComponent::AcceptQuest` to notify QuestSubsystem
  - Added extensive logging throughout quest system

#### What did we learn?
- Raycast collision channels are critical for interaction detection
- ECC_Pawn only hits Characters/Pawns, not StaticMesh Actors
- TextRenderComponent needs manual rotation for billboard effect
- Interface methods with BlueprintNativeEvent need `_Implementation` suffix

#### Problems & Solutions
- **Problem:** Collectible not detected by raycast
  - **Cause:** Raycast uses ECC_Pawn, collectibles are StaticMesh Actors
  - **Attempted:** Changed to ECC_Visibility, broke NPC detection
  - **Status:** UNRESOLVED - needs Blueprint collision preset fix

- **Problem:** NPC prompt not visible
  - **Cause:** TextRenderComponent not facing camera
  - **Solution:** Added billboard effect in Tick (FindLookAtRotation)

- **Problem:** Quest events not triggering for all quests
  - **Cause:** NotifyQuestEvent only checked specific QuestID
  - **Solution:** Added loop to check all active quests when QuestID is NAME_None

**Collectible Raycast Detection**
- Player raycast uses `ECC_Pawn` channel
- NPCs are Characters (Pawns) → detected ✅

**Recommended Fix:**
1. Open `BP_QuestCollectible` in editor
2. Select `MeshComponent`
3. Set Collision Preset to `BlockAllDynamic`
4. OR create custom collision channel for interactables
