## Technical Decisions

### Combat System Architecture
**Component-Based Design:**
- `UCombatComponent` - Main combat manager (combo chains, hit detection, state)
- `UAnimNotifyState_MeleeCollision` - Collision detection during animations
- `UCombatComboData` - DataAsset for combo configuration
- `ICombatInterface` - Interface for damageable actors

**Smart Input Routing:**
- Left Mouse Button context-aware:
  - Armed: `WeaponComponent->StartFiring()`
  - Unarmed: `CombatComponent->StartAttack(Light)`
- Automatic detection via `GetCurrentWeapon() != nullptr`

**Combo System:**
- Input buffering with combo windows
- Timer-based window management (ComboWindowStart/End)
- Hit registration to prevent double-hits
- Configurable combo chains via DataAsset
