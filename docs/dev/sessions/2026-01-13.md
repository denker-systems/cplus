## Critical Issue: Collectible Raycast Detection

### Problem
Player raycast uses `ECC_Pawn` collision channel to detect interactables.
NPCs are Characters (Pawns) so they are detected.
Collectibles are StaticMesh Actors - they are NOT detected by ECC_Pawn.

### Attempted Solutions (Failed)
1. ❌ Changed raycast to ECC_Visibility - broke NPC detection
2. ❌ Added ECC_Visibility response to collectible mesh - still not detected
3. ❌ Added ECC_Pawn response to collectible mesh - actors don't respond to Pawn channel

### Solution (VERIFIED WORKING)
**Blueprint Collision Preset:**
1. Open `BP_QuestCollectible` → Select `MeshComponent`
2. Set **Collision Presets** → `Custom`
3. Set **Pawn** → `Block`
4. Set **Visibility** → `Block`

**Result:** Raycast (ECC_Pawn) now detects collectible. Interaction works.
